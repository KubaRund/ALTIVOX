# Hlášení bezpečnostních problémů

Pokud GitHub na kartě **Security → Report a vulnerability** nabízí soukromé hlášení, použijte jej. Jinak si vyžádejte soukromý kontakt přes veřejný profil správce [KubaRund](https://github.com/KubaRund); do veřejného issue napište nejvýše žádost o neveřejný kanál bez citlivých podrobností.

Uveďte dotčenou komponentu a commit, dopad, podmínky a minimální reprodukci na vlastních testovacích datech. Nepřikládejte skutečné přístupy, osobní údaje, exporty provozu nebo soukromé odkazy místností a akcí. Aktivně nezkoušejte cizí účty a nerušte živé akce.

Projekt nemá garantovanou dobu reakce, placený bug bounty program ani samostatně podporované starší větve. Opravy se soustředí na aktuální `main`; provozovatel si musí zajistit nasazení oprav a aktualizaci PHP i hostingu.

Technické hranice a práce s daty jsou popsané v [bezpečnostní dokumentaci](docs/bezpecnost.md).
